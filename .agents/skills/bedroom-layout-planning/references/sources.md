# 参考资料与适用边界

使用评分、人体尺度或规范判断时，先确认标准仍为现行版本。标准只提供通用基线；用户测量数据和产品数据仍由本次任务输入。

## 住宅与安全底线

- [GB 55038-2025《住宅项目规范》](https://ghzrzyw.beijing.gov.cn/biaozhunguanli/bzzl/202506/P020250609570099619169.pdf)：全文强制性工程建设规范，2025-05-01 实施。可用于核对卧室基本功能、面积/短边、净高、户内过道与门净宽、采光通风和安全底线。既有住宅室内摆放是否适用具体条款，需要结合改造性质和所在地要求判断。

## 人体工效学与家居

- [GB/T 10000-2023《中国成年人人体尺寸》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=B19DCCA575D9406856ABF87A511EE11F)：现行人体尺寸基础数据；用于有明确使用者画像时选择百分位，不直接生成统一通道宽度。
- [GB/T 44384-2024《人-系统交互工效学 健康家居设计导则》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=A31C226A1680B034547721E91444ACC2)：现行健康家居设计导则；用于构建设计评分维度，不把推荐性内容写成强制碰撞规则。
- [GB/T 43518-2023《人类工效学 家居无障碍设计导则》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E06F1A9C7B17EAE32DB895300DDC49F0)：只在用户选择无障碍/适老画像或项目确有要求时启用相应指标。
- [GB/T 39223.3-2020《健康家居的人类工效学要求 第3部分：办公桌椅》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=AB56A8DEFF95BC4F3D565BB75F304C2F)：用于卧室书桌椅尺度与使用评价。

## 家具尺寸与产品质量

- [GB/T 3326-2016《家具 桌、椅、凳类主要尺寸》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=0C497FF8C85FCAE7A6D790CE5D4F8BA5)：用于桌椅凳名义尺寸核对；具体产品外廓优先。
- [GB/T 3324-2024《木家具通用技术条件》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=96019B083A5A59FC7F84895DFFE7500B)：用于木家具通用质量和安全背景，不直接提供布局评分。

## 使用原则

- 只有读到标准正文支持的数值才可作为引用值；不得根据标准标题猜测数字。
- 强制标准、推荐标准、项目默认值和用户偏好必须分别标注。
- 标准更新或适用地区不明时，报告版本和不确定性，必要时要求专业设计人员复核。
